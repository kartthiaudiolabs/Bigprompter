# BIG PROMPTER — PRODUCT REQUIREMENTS DOCUMENT (PRD) v1.0

## 1. Product Identification
- **Product Name:** BIG PROMPTER
- **Tagline:** Think Bigger. Prompt Better.
- **Product Promise:** You bring the idea. BIG PROMPTER engineers the prompt.
- **Category:** Multi-Model AI Prompt Engineering & Prompt-to-Production Operating System
- **Document Version:** 1.0.0
- **Status:** Phase 0 Baseline

---

## 2. Product Vision & Mission
BIG PROMPTER bridges the gap between raw, ambiguous human intent and production-grade, highly reliable AI instructions. It operates as an autonomous Senior Prompt Engineer that:
1. Deconstructs raw ideas, drafts, business specifications, and existing prompts.
2. Identifies requirement gaps and conducts adaptive discovery via targeted multiple-choice inquiries.
3. Designs prompt architectures conforming to L1 (Basic), L2 (Advanced), L3 (Professional), or L4 (Production) specifications.
4. Customizes prompt syntax to target model architectures (Claude XML delimiters, Gemini schema alignment, OpenAI delimiters, DeepSeek chain-of-thought rigor).
5. Defends against prompt injection and jailbreaks using untrusted input isolation boundaries.
6. Evaluates prompt quality, estimates inference costs, and provides an isolated execution sandbox.

---

## 3. Target User Personas
- **Software Engineers & AI Developers:** Requiring deterministic output contracts, JSON schemas, CI/CD integration, and injection guardrails.
- **Content Creators & Marketers:** Building high-converting copywriting frameworks without generic AI clichés.
- **Creative & Audio Producers:** Calibrating music mixing, frequency chains, and creative direction.
- **Data Analysts & SQL Developers:** Synthesizing optimized, dialect-specific queries with execution plans.
- **Enterprises & Legal / Compliance Specialists:** Requiring data isolation, GDPR/privacy boundaries, and audit trails.

---

## 4. Product Engineering Levels (L1 – L4)
| Level | Name | Scope & Deliverable |
|---|---|---|
| **L1** | Basic | Clean objective, context, direct instructions, and expected output. |
| **L2** | Advanced | Role persona, mission context, negative constraints, tagged delimiters, and structured examples. |
| **L3** | Professional | Requirement architecture, conditional logic, execution phases, few-shot demonstrations, and verification checklists. |
| **L4** | Production | Industrial agent architecture: model-tailored syntax, strict prompt injection defense (`<untrusted_user_input>`), runtime variable schemas, edge case recovery matrix, and deployment code snippets. |

---

## 5. Non-Negotiable Product Principles
1. **User Authority:** Consequential decisions and deployments require explicit user confirmation.
2. **Privacy by Design:** Tenant and project isolation; zero plaintext credentials; private by default.
3. **Evidence Before Claims:** No fabricated benchmark or test results; distinguish automated estimates from measured executions.
4. **Adaptive Complexity:** Provide lightweight prompts for simple tasks; activate deep architectures only when complexity justifies it.
5. **Prompt Injection Defense:** Strict separation between trusted instructions and untrusted runtime data.
