# BIG PROMPTER

> **Think Bigger. Prompt Better.**  
> An autonomous multi-model Prompt Engineering Operating System that turns ambiguous ideas into production-ready L1–L4 prompt architectures.

---

## Highlights

- **Adaptive Socratic Discovery**: 4-question interactive interview that extracts domain boundaries, constraints, and eliminates contradictions.
- **Visual Prompt Architecture**: 5-tier structural schematic featuring System Context, Domain Scope, Contract Boundary, Delimited User Input, and Defensive Guardrails.
- **Multi-Model Sandbox & Real-Time Streaming**: Stream across Anthropic Claude 3.7, OpenAI GPT-4o, Google Gemini 2.5, and an Offline Deterministic container without mandatory API keys.
- **Specialist Multi-Agent Consensus**: 4 autonomous review agents (Security Auditor, Domain Specialist, Quality Evaluator, Architecture Reviewer).
- **Adversarial Injection Test Battery**: 5-vector injection battery (Direct Override, System Leak, Role Breakout, Jailbreak, Protocol Smuggling).
- **Production SDK & Code Export**: Instantly export to TypeScript, Python, Next.js Edge routes, cURL scripts, and LangChain/PromptFoo pipeline configurations.

## Getting Started

### Prerequisites
- [Bun](https://bun.sh/) (recommended) or Node.js 18+

### Installation
```bash
git clone https://github.com/kartthiaudiolabs/Bigprompter.git
cd Bigprompter
bun install
```

### Development Server
```bash
bun run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Test Suite
Run the unit test suite (68 tests across 15 test suites):
```bash
bun run test
```

### Production Build
```bash
bun run build
bun run start
```
